# Stage 1 approval checklist

Please test these on your own computer and phone, then tell me what failed (or say **"Stage 1 approved"**).
Tick each line as you go. Use the phone's normal camera app to scan.

## A. Open it
- [ ] Double-clicking `index.html` opens the home page, with orange and cream colors and no broken pictures.
- [ ] The menu links (Home, Create, Templates, How it works, About) all open.
- [ ] On your phone (or by making the browser window narrow), the menu button opens and closes the menu.

## B. Make and scan codes (the most important test)
Make each code, download the PNG, show it on your screen or print it, and scan it with a phone.

- [ ] **Website link** `example.com` opens example.com.
- [ ] **Wi-Fi** for your own network: the phone offers to join. Try a password with only numbers, and a password with a `;` or `:` in it.
- [ ] **Contact card**: the phone offers to add the contact, with the name, phone and email correct.
- [ ] **Email**: opens a new email to the right address with the subject filled in.
- [ ] **Phone call**: offers to call the number.
- [ ] **Text message**: opens a text to the number with the message ready.
- [ ] **WhatsApp chat**: opens a WhatsApp chat with the number.
- [ ] **Social profile** (try Instagram and one more): opens the profile.
- [ ] **Plain text** shows the text.

## C. Design
- [ ] Each of the 12 templates still scans.
- [ ] Try each dot pattern, and the corner shapes. Each still scans.
- [ ] A gradient code scans.
- [ ] A code with a logo scans. Try the round profile picture too.
- [ ] Make the dots very pale on purpose. The scan check says **May not scan**.
- [ ] Choose a transparent background and place the PNG on a white page. It still scans.

## D. Downloads and sharing
- [ ] PNG 512, 1024 and 2048 all download and open.
- [ ] The SVG downloads and opens in the browser. It stays sharp when zoomed in.
- [ ] **Copy image**, then paste into a message or document.
- [ ] Facebook, WhatsApp, LinkedIn and X open their own share screens in a new tab (using a website-link code). Nothing is posted until you confirm there.
- [ ] **Copy link** puts the web address in the clipboard. (When you open the site by double-clicking, there is no web address for the site itself, so this button is only on for link-type codes.)
- [ ] On a phone, **Instagram** or **Share image** opens the phone's share sheet. On a computer, **Instagram** saves the image.

## E. Mistakes
- [ ] Type `javascript:alert(1)` as a web address. It is refused with a clear message.
- [ ] Press **Download PNG** with an empty form. It tells you what to fix.
- [ ] Upload a text file as a logo. It is refused with a clear message.

## F. Look
- [ ] The pages look good on your phone and on a large screen. Tell me anything that looks wrong, crowded or hard to read.
- [ ] Anything on a page that you do not understand? Tell me and I will rewrite it in simpler words.

When everything passes, say **"Stage 1 approved"**. Only then do we plan Stage 2.
