    Scan check

    A pretty code is no use if it does not scan

    Pale dots, a missing border or a very large logo can stop phones from reading a code. QR Signature tests your design as you work and tells you in plain words what to fix, before you print anything.

    • Contrast between the code and its background
    • Empty border around the code
    • Logo size and error correction
    • How much data the code holds, and the smallest size to print

      Questions

      Is my information sent anywhere?

      No. The code is made inside your browser. What you type, and any logo you add, stay on your device. The share buttons only open each network's own page when you click them, and they carry the link you chose to share, nothing else.

      Will my code stop working one day?

      The codes made here hold their information inside the pattern itself, with no server in between. They keep working for as long as the thing they point to still exists. A web page that is taken down will not open, however well the code scans.

      Should I download a PNG or an SVG?

      Use PNG for screens, slides and social posts. Use SVG for printing, because it stays sharp at any size. If you are unsure, take both.

      Can I put my logo in the middle?

      Yes. The code then uses its strongest error correction so it can still be read. Keep the logo small, and test the code with a couple of phones before you print.

      How big should I print it?

      The scan check shows the smallest size for your code. As a rule of thumb, a phone can read a code from about ten times its width away, so a code that people scan from a poster across a room needs to be much larger than one on a business card.
